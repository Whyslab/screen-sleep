Окно настроек того, что делает сессия Hyprland, когда ты перестал её трогать —
приглушение, блокировка, гашение экрана, сон — плюс ночной фильтр по
расписанию. Правит `hypridle.conf` за тебя, держит отдельные тайминги для сети
и батареи и сам переключается между ними, когда воткнул зарядку.

## Что внутри

- **Окно вместо файла конфигурации.** `hypridle.conf` генерируется из того, что
  ты выставил. Трогается только блок между двумя маркерами — твой раздел
  `general`, твой `lock_cmd` и всё остальное написанное руками остаётся как есть.
- **Два набора, переключаются сами.** Один комплект таймингов для сети, другой
  для батареи. Демон замечает подключение или отключение зарядки за ~15 секунд,
  перегенерирует конфиг и перезапускает hypridle. Набор батареи можно править,
  сидя от розетки, — он просто запомнится до нужного момента.
- **Каждый шаг выключается отдельно.** Снял галочку с *Suspend* — компьютер
  блокируется, но сам никогда не засыпает. Снял все — не происходит ничего.
- **Пресеты.** Normal (60/70/80/120), Movie (не происходит ничего),
  Power saving (5/7/8/15).
- **Не засыпать.** Одна кнопка держит блокировку `systemd-inhibit`: ни
  приглушения, ни блокировки, ни сна — при любых настройках выше. Для фильма
  или выступления.
- **Ночной фильтр с плавным переходом.** Экран не прыгает на 2700 K в 22:00 — он
  снижается на 500 K каждые 15 минут, так что момент перехода не замечаешь.
  Утром возвращается мгновенно.
- **Подхватывает то, что уже есть.** При первом запуске читает существующий
  `hypridle.conf` и стартует с этих таймингов. Установка не меняет молча то,
  когда у тебя блокируется экран.

### Единственное, что стоит понять

Каждый шаг отсчитывается от **последнего касания мыши или клавиатуры**, а не от
предыдущего шага.

```
последний ввод
    │
    ├── 60 мин ──▶ приглушить экран
    ├── 70 мин ──▶ заблокировать
    ├── 80 мин ──▶ погасить монитор
    └── 120 мин ─▶ уйти в сон
```

То есть «заблокировать 70» значит *на 70-й минуте бездействия*, а не «через 70
минут после приглушения». Порядок по возрастанию времени — почти всегда то, что
нужно; окно предупредит, если шаги идут не по порядку, но не запретит.

## Требования

- Сессия Hyprland (всё применяется через `hyprctl`)
- Python 3.11+ с привязками GTK 3 — на Arch: `python-gobject`, `gtk3`
- `hypridle` — цепочка простоя
- `hyprsunset` — ночной фильтр, запускается из `exec-once = hyprsunset`
- `brightnessctl` — шаг приглушения
- Опционально: `libnotify` (уведомление при смене питания),
  `systemd-inhibit` (часть systemd; кнопка «не засыпать»)

Root не нужен нигде. Всё живёт в домашнем каталоге.

## Установка

```bash
git clone https://github.com/Whyslab/screen-sleep.git
cd screen-sleep
./install.sh
```

Установщик кладёт код в `~/.local/share/screen-sleep`, добавляет пункт в
лаунчер и включает пользовательскую службу, которая выполняет расписание.

Посмотреть, что будет сделано, ничего не делая: `./install.sh --dry-run`.
Попробовать на временном каталоге: `./install.sh --prefix /tmp/ss-test`.

### После установки

Открой **Screen & Sleep** из лаунчера или повесь на клавишу:

```bash
bind = SUPER SHIFT, N, exec, python3 ~/.local/share/screen-sleep/gui.py
```

С `--night` окно откроется сразу на вкладке ночного фильтра.

Ночному фильтру нужен запущенный `hyprsunset`:

```bash
exec-once = hyprsunset      # в hyprland.conf
```

## Как это устроено

Три части, намеренно разделённые:

| Часть | Задача |
|---|---|
| `gui.py` | окно; пишет `config.json`, сразу применяет набор |
| `daemon.py` | цикл раз в 15 с: выполняет расписание, следит за питанием |
| `idle.py` | генерирует `hypridle.conf` и перезапускает hypridle |
| `night.py` | считает, какая температура должна быть прямо сейчас |

`hypridle` не умеет перечитывать конфиг и ничего не знает про батарею, поэтому
смена набора — это переписывание файла и перезапуск процесса. Переписывается
только управляемый блок:

```
# >>> screen-sleep: this block is managed by the Screen & Sleep window
# Edits inside this block are overwritten. Everything outside it is kept.
# Profile: on AC power.

$dim_timeout  = 3600   # 60 min — dim the backlight
$lock_timeout = 4200   # 70 min — lock the screen (starts hyprlock)

# Dim early, as a gentle warning that the lock is coming
listener {
    timeout = $dim_timeout
    on-timeout = brightnessctl -s set 10%
    on-resume = brightnessctl -r
}
...
# <<< screen-sleep
```

Если перезапуск почему-то не удался, обратно записывается прежний конфиг и
hypridle поднимается с ним — неудачная правка не оставит тебя с сессией,
которая никогда не блокируется. Первая версия файла к тому же сохраняется
рядом как `hypridle.conf.bak-<дата>`.

### Ночной фильтр

`compute_target_temperature` отвечает на один вопрос: какая температура должна
быть *прямо сейчас*, исходя из часов и расписания. Демон спрашивает каждые 15
секунд и применяет ответ, если он изменился, — поэтому расписание корректно
после выхода из сна, после перезагрузки и если компьютер весь вечер был выключен.

Движение слайдера руками ставит `manual_override`, и демон не трогает
температуру до пересечения ближайшей границы расписания. Осознанный выбор
переживает демона — просто не переживает до завтра.

## Настройка

`~/.config/screen-sleep/config.json` пишется окном — править руками не нужно,
но никто не мешает:

```json
{
  "night": {
    "target_temp": 2700, "on_hour": 22, "on_minute": 0,
    "off_hour": 7, "off_minute": 0, "manual_override": false
  },
  "idle": {
    "ac":      { "lock": { "enabled": true, "minutes": 70 } },
    "battery": { "lock": { "enabled": true, "minutes": 7 } }
  }
}
```

Всё битое, выходящее за границы или не того типа зажимается или заменяется, а не
роняет программу: обрезанный файл оставляет тебя с рабочими значениями по
умолчанию, а не с окном, которое не открывается.

Скорость перехода живёт в `common.py`: `RAMP_STEP` (500 K) и
`RAMP_INTERVAL_MIN` (15 мин). `RAMP_BOTH_DIRECTIONS` выключен — поэтому утром
возврат мгновенный.

## Чего это не умеет

- **Только Hyprland.** Цепочка простоя — hypridle, фильтр — hyprsunset, запасных
  вариантов нет. На другом композиторе не работает ничего.
- **Расчёт на один экран.** Шаг приглушения использует `brightnessctl`, то есть
  встроенную панель. На десктопе с внешними мониторами толку от него не будет.
- **Демон должен быть запущен**, иначе не работают ни расписание, ни
  переключение сеть/батарея. Окно об этом скажет, но само включить отключённую
  пользовательскую службу не может.
- **Цвет слайдера следует теме GTK.** Окно задумано монохромным, но тема с
  сильными правилами акцента всё равно может его подкрасить.
- **Нет автоматических блокировок по приложениям.** «Не засыпать» — ручной
  переключатель, а не слежение за тем, что играет видео.

## Удаление

```bash
./uninstall.sh              # снести программу, настройки оставить
./uninstall.sh --purge      # плюс конфиг и сохранённое состояние
```

`hypridle.conf` намеренно не трогается. Управляемый блок внутри — обычная
конфигурация hypridle, она продолжает работать. Убери его руками или восстанови
один из файлов `hypridle.conf.bak-*`, если хочешь вернуть прежнее поведение.

## Разработка

```bash
pip install pytest ruff
pytest tests/ -q
ruff check .
```

37 тестов, ни одному не нужен ни экран, ни сессия Hyprland. Покрыто расписание
(включая окно, пересекающее полночь, — именно там такой код обычно ломается),
загрузка конфига из обрезанных и покорёженных руками файлов и генерация
`hypridle.conf`: что повторная запись заменяет блок, а не дописывает, что смена
набора не накапливает listener'ы и что написанное вручную вне маркеров всегда
переживает перезапись.
